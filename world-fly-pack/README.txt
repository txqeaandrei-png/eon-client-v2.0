EoN World Fly behavior pack

This pack enables Bedrock's mayfly ability in a world that has the pack enabled.
It is world-scoped: it does not change the launcher or unrelated worlds.

Install
1. Open EoN-World-Fly.mcpack with Minecraft to import it.
2. In the target world's settings, turn Cheats on and enable EoN World Fly
   under Behavior Packs.
3. Join the world and double-tap jump to start flying. Hold jump to ascend
   and crouch to descend.

To disable flight for tagged players before removing the pack, run:
  /function eon_world_fly/disable

This pack uses the world command system and requires cheats. Only enable it
in worlds you own/control. A LAN-hosted world can grant flight to other players
in that world too; do not enable it on multiplayer worlds.
